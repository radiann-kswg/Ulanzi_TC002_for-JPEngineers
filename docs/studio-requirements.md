# Ulanzi TC002 JPエンジニア向けOS設定の要件

2026年11月24日。対象は Windows で自分の TC002 を設定する利用者。TC002 の既存 Linux 上で動く独自時計アプリ、PC 側の設定アプリ、セットアップ手順をひとつのリポジトリから利用できるようにする。

| 機能 | 完了条件 |
| --- | --- |
| Windows 設定アプリ | 日本語の画面をリポジトリから起動できる。時計の IP、天気の地点、GitHub の監視先を保存し、PC ブリッジを起動・停止できる。入力エラーは画面に表示し、他の設定項目を保持する。 |
| 天気の地点選択 | 日本の地名・住所の候補、地図上のクリック、またはキーボードで取得地点を選び、時計の表示名を編集できる。確定で入力欄に反映し、設定の保存は利用者が行う。通信できないときも地点名・座標を直接入力できる。地図と住所検索の出典を画面と説明書に表示する。 |
| ナビゲーションと接続先 | 右側のメニューとキーボードで「接続と表示」「OS セットアップ」を切り替え、編集内容とスクロール位置を保持する。「対象の時計」には時計画面の表示例と保存済みの IPv4 を示し、PC ブリッジの稼働状態は「状態を確認」で照会できる。 |
| 進行状況とキーボード操作 | ページ共通の画面下部に処理中の表示、結果、エラーを出す。Ctrl+S で接続設定を保存でき、Tab で画面外の入力欄に移ったときはその欄が見える位置にスクロールする。 |
| プロジェクト生成とビルド | 初回チェックアウトから固定版の公式サンプルと FlyThings Z21 SDK を使い、独自プロジェクトを生成する。SDK を配置したドライブやユーザー名を固定しない。 |
| 一時実行 | 保存済みの時計を対象に、Windows アプリからビルドを一時実行し、工場アプリへ戻せる。操作結果と失敗理由を表示する。 |
| Wi-Fi による常設 | OS セットアップ画面で、保存済みの時計から標準の秒針音を個人用のビルドに取り込める。標準アプリ 1.1.4 の OTA による書き込みと再起動後の照合手順を開ける。 |
| TF カードへのコピー（任意） | 公式 IDE の Image Build で生成した独自プロジェクトの `update.img` を、選んだ FAT32 カードのルートへコピーし、読み戻して照合する。書き込み前に対象を確認し、完了時に SHA-256 を表示する。 |
| 公開準備 | 独自ファームウェアは GPL-3.0-or-later、Windows アプリは MIT。第三者の表示を保持し、SDK・実機由来の素材・個人設定・収集データを公開物から除く。 |

各機能を個別にコミットし、要件との一致と通常操作・失敗時の挙動をレビューする。クリーンな作業ディレクトリで試した範囲と、実機または物理カードが必要な検証を区別して記録する。
